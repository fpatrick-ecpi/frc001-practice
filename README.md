# FRC001 practice repository

This is a practice copy for FRC001, the Canvas course for ECPI subject matter experts. It holds a pretend course, PRC101, so you can practice reading files, history and pull requests on GitHub.

Nothing here is real ECPI course content, and nothing here reaches a student box. ECPI's real course repository is private and works the same way.

## What is here

- `courses/SME_GUIDE.md`: a short practice guide for subject matter experts.
- `courses/prc101/`: the pretend course.
- `.github/`: the automatic checks that run on every pull request.

## Make your own copy

Press **Use this template**, then **Create a new repository**. Pick your own account as the owner and give it a name, like `my-frc001-practice`. Your copy has the same files, the same checks, and a practice bot.

In your copy, press **Issues**, then **New issue**, then **Practice request**. Fill it in and press **Create**. The practice bot answers in about a minute. If something needs fixing, it says what. When your request is right, it puts the change on a branch and gives you a link to open the pull request. You watch the checks and merge it yourself.

The practice bot only answers the owner of the copy.
