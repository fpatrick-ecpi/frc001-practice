# Practice guide for subject matter experts

This guide is practice material for FRC001. It is short on purpose.

## How a change gets in

1. You ask for a change with a request form.
2. A bot makes the change on its own branch and opens a pull request.
3. Automatic checks run on the pull request.
4. The system owner reads the change and merges it.

## Writing for students

- Write short, active sentences.
- Spell out every acronym the first time you use it.
- Say each thing once.
- Never put a password, a key, a student's name or a grade in a request.

## Before you ask

Have two things ready: the course code, and one sentence on why students need the change.
